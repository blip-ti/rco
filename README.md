# Информатика 7–9 классы | Учебный интерактивный портал

Интерактивный веб-сайт для преподавателей и учащихся с конспектами уроков, домашними заданиями, ответами, ссылками на презентации и трекингом прогресса.

## 🚀 Быстрый запуск

1. Клонируйте репозиторий:
```bash
git clone <ссылка_на_ваш_репозиторий>
cd <папка_проекта>
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите локальный сервер разработки:
```bash
npm run dev
```

Сайт откроется по адресу `http://localhost:3000`.

## ⚙️ Сборка для продакшена

```bash
npm run build
```

## ✨ Возможности
- 69 учебных тем (7, 8, 9 классы).
- 69 пошаговых 20-минутных конспектов уроков.
- Переключение тёмной и светлой темы (Dark / Light Mode).
- Прямые ссылки на PDF-презентации к каждому уроку.
- Интерактивные отметки «Тема пройдена» и «ДЗ задано» с сохранением в `localStorage`.
- Поиск и фильтрация по темам и классам.
